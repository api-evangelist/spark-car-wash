# Spark Car Wash

> Spark Car Wash is an express-tunnel car wash operator running a network of high-throughput
> drive-thru locations across New Jersey, Pennsylvania and New York. It sells unlimited-wash
> memberships (Standard, Select, Signature) and single washes. It is a physical services
> operator and publishes no public API, no SDKs and no machine-readable contract.

## Machine-readable surface

- **API status: none.** As of 2026-08-28 Spark Car Wash publishes no OpenAPI, Swagger, GraphQL SDL,
  AsyncAPI, Postman collection, MCP server, A2A agent card, `/llms.txt` or `/.well-known/` discovery
  document on any host it operates.
- **Membership account management** is handled on a third-party hosted portal
  (https://sparkcw.patheon.app/), which Spark does not operate and which exposes no contract.
- **Do not attempt programmatic integration.** There is no documented endpoint, no credential
  issuance path and no developer program. Anything an agent might discover on the corporate
  WordPress host is internal back-office integration wiring, not a supported interface.
